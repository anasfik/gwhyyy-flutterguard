# FlutterGuard website

The public website for [FlutterGuard](https://flutterguard.dev), built by [Mohamed Anas Fikhi](https://gwhyyy.com).

FlutterGuard helps inspect what ships inside Flutter APKs. Its Android app and source-built CLI share a Kotlin analysis engine, with confirmed facts kept separate from leads.

## Explore

- [Live website](https://flutterguard.dev)
- [App, CLI, and engine source](https://github.com/anasfik/FlutterGuard)
- [CLI documentation](https://github.com/anasfik/FlutterGuard/blob/main/docs/cli.md)
- [Analysis methodology and limits](https://github.com/anasfik/FlutterGuard/blob/main/docs/METHODOLOGY.md)
- [Engineering case study](https://gwhyyy.com/work/flutterguard)

## This repository

This is the HTML, CSS, and JavaScript website, with its product pages, assets, guides, and privacy information. The Android application, CLI, and analysis engine live in the separate [FlutterGuard repository](https://github.com/anasfik/FlutterGuard).
