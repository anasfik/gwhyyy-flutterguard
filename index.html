Before you install

Download the signed APK from GitHub releases. Android 8 or newer.

Static analysis records what the APK contains; it is evidence, not proof. Scan only apps you own or are authorised to test. Scans can take minutes.

Switching between Play and GitHub builds requires an uninstall, which deletes local reports, settings and history. Export first; exports are not a history restore.
